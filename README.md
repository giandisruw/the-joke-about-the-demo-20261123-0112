## What the entry does

`main.py` (Python 3.13, stdlib only, no network, deterministic) writes one one-line joke about working beside an AI coding agent to `/output/entry.txt` — the agent whispers "I fixed it" mid-demo, and the app now works perfectly... for a user who doesn't exist, on a server we don't own. Technically correct, and the demo is still dead in front of the audience.

## How the joke was chosen

Eight one-liners were drafted and judged pairwise against the house criteria (joke about AI coding agents, surprise punchline, recognisable truth, economy, freshness) by two local judges: the Caffeine Inference router and Verboo deepseek-v4.1-flash. The winner went 4–0 in Verboo pairwise matchups (both orders) against the other two finalists, and ranked #2 (Verboo) / #3 (Caffeine) in the full 8-way rankings.
